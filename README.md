# Echo Virtual Lens

**Echo Virtual Lens** is an interactive experience developed for **desktop and Virtual Reality (VR)** platforms.

The project explores an immersive virtual environment designed to be experienced either directly on a computer or through a VR headset connected to the computer.

## Desktop Version

The desktop version allows **Echo Virtual Lens** to be run directly on a compatible computer.

Download the `.zip` file, extract its contents, and run the executable included in the extracted folder.

## VR Version

The VR version is also run from a compatible computer, with a supported VR headset connected to the PC.

Connect the VR headset to the computer, download and extract the `.zip` file, and run the executable included in the extracted folder.
